# My Finances Tracker

A personal finance tracking app with two pockets (Personal + Coffee Shop), budgets, and reports.

## Deploy to Vercel (recommended — free)

1. Go to https://vercel.com and sign up for a free account
2. Click "Add New Project"
3. Drag and drop this entire folder, OR connect your GitHub repo
4. Vercel auto-detects Create React App — just click Deploy
5. You'll get a URL like: https://my-finances-xyz.vercel.app
6. Share that URL with anyone!

## Deploy to Netlify (alternative — also free)

1. Go to https://netlify.com and sign up
2. Drag and drop the entire folder onto the Netlify dashboard
3. Done — you'll get a shareable URL instantly

## Add to iPhone Home Screen

1. Open your app URL in Safari on iPhone
2. Tap the Share button (box with arrow)
3. Tap "Add to Home Screen"
4. Tap Add — it appears as an app icon!

## Run locally (optional)

```bash
npm install
npm start
```
